# Employee Performance Analysis 📊

This repository contains the solution for the Data Analysis & Probability exam project.

### 📂 Files Included in this Repository:
* **`Exam_Solution.ipynb`**: The Jupyter Notebook containing all the Python code, statistical calculations, and data visualization.
* **`Exam_Report.pdf`**: The final comprehensive report containing Part A (Theory answers) and Part B (Practical outputs and Executive Insights).
* **`employee_performance.csv`**: The 4000-record dataset generated and used for this analysis.

### 🛠️ Tech Stack Used:
* Python (Pandas, NumPy)
* Data Visualization (Matplotlib, Seaborn)
* Statistics (SciPy)
